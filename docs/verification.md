# Verification protocol

1. Obtain the **current official Diocese of Leeds Ordo** and the applicable England national calendar.
2. For each diocesan observance, record the exact Ordo title, year and page/section reference.
3. Verify date, rank, any transfer rules and whether it applies to the entire diocese or only the cathedral/parish.
4. Enter as `draft`; promote to `verified` only after checking against the source.
5. Compare generated output for Sundays, solemnities, Lent, Holy Week, Easter and Advent before publication.
6. Preserve an audit trail of changes between Ordo years.

**No diocesan observances have been verified in Build 1.** Do not publish an authoritative calendar from this dataset.

The Romcal development documentation lists England and some English diocesan packages; verify the current package API and dependency version before implementing the runtime adapter.
